# key-guide-social

Public image and Reel files for The Key Guide's scheduled Instagram and Facebook posts, served by GitHub Pages at https://davida25666.github.io/key-guide-social/. Make's Key Guide scenarios read the file URLs from the Key Guide social queue.

- `w1/`: week one photo posts
- `m2/`: photo posts from Oct 27 to Dec 17
- `reels/`: Friday Reels
